# Madina Electronics Manager Bot

A Telegram-based inventory and sales manager for Madina Electronics. The bot
reads and updates the live Google Sheet and provides a guided button interface
for non-technical users.

## Manager v1 features

- Professional Telegram main menu
- Product and stock search
- Guided stock additions
- Guided cash, bank, and credit sales
- Confirmation before every stock-changing transaction
- Automatic `Transactions` worksheet and audit trail
- Low-stock report
- Daily sales and payment summary
- English and simple Roman Urdu prompts
- Optional Telegram user allowlist
- Helpful Telegram error messages

## Required Railway variables

| Variable | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Complete token generated by BotFather |
| `GOOGLE_SHEET_ID` | The ID between `/d/` and `/edit` in the sheet URL |
| `GOOGLE_CREDENTIALS_JSON` | Complete Google service-account JSON |
| `AUTHORIZED_USER_IDS` | Recommended comma-separated Telegram IDs, for example `123456789,987654321` |
| `LOW_STOCK_THRESHOLD` | Optional; defaults to `3` |

After changing Railway variables, deploy the staged changes.

## Google Sheet permission

The bot now records transactions and changes quantities. Share the spreadsheet
with the `client_email` inside `GOOGLE_CREDENTIALS_JSON` and select **Editor**.
Viewer access is no longer sufficient.

## Stock worksheet format

The bot checks all worksheets except `Summary`, `Transactions`, `Sales`, and
`Expenses`. It searches the first ten rows for recognizable headings.

Recommended headings:

| Brand | Category | Model | Variant | Qty |
|---|---|---|---|---:|
| PEL | Refrigerator | PRGD 21850 | Silver | 4 |

Accepted alternatives include `Quantity` or `Stock` for `Qty`, and `Company`
for `Brand`. The quantity column and at least one product-description column
must be present.

The bot automatically creates a `Transactions` worksheet when the first stock
addition or sale is confirmed. Do not rename its columns.

## First deployment

1. Deploy the GitHub repository on Railway.
2. Set the start command to `python bot.py` if Railway does not detect it.
3. Open the bot in Telegram and send `/id` from each approved account.
4. Add those numbers to `AUTHORIZED_USER_IDS` in Railway and redeploy.
5. Send `/start` or `/menu` to open the manager menu.
6. Press **Refresh** and confirm that product rows are loaded.
7. Test one stock addition and one sale with a non-critical product.

## Commands

- `/start` or `/menu` — open the main menu
- `/refresh` — reload the Google Sheet
- `/cancel` — cancel the current operation
- `/id` — show the current Telegram user ID

Normal product names can also be typed directly for a quick stock search.

## Security notes

- Keep the bot token and Google service-account key private.
- Configure `AUTHORIZED_USER_IDS` before real business use. If it is empty,
  anyone who discovers the bot can use its manager actions.
- If a bot token appears in logs or messages, revoke it with BotFather and
  replace it in Railway.
- Transactions are appended to the audit sheet instead of being silently
  overwritten.

## Current scope

Manager v1 handles existing products, quantities, sales, and daily summaries.
Future modules can add new-product creation, purchases, expenses, customer
accounts, supplier balances, returns, invoices, profit calculations, scheduled
reports, and PostgreSQL-backed accounting.
